# ♠ 德州扑克 · 朋友局 (No-Limit Texas Hold'em, play money)

在线玩：**https://kunyi523.github.io/holdem/**

免费、纯网页、无需注册的无限注德州扑克，给朋友们娱乐用。
**仅使用虚拟筹码**：每人 100,000 娱乐筹码，没有充值、没有真钱、没有任何支付功能。

## 怎么玩（中文）

**开房间（房主）**
1. 打开网址，输入昵称，点「创建房间」。
2. 弹出房间码和邀请链接，点「复制邀请链接」发到微信群。
3. 朋友到齐后点牌桌中间的「▶ 开始游戏」。人不够可以点空位「＋添加AI」（粉哥 / Micheal / Grok Bot / 小龙 …）。点任意 AI 的座位可以查看它的性格和本局数据，房主还能直接给它换性格。
4. 左上角 ☰ 菜单：调盲注（默认 500/1,000）、行动时间、补码到 100,000、移除玩家、暂停。

**加入（朋友）**
1. 点房主发的链接（或在首页输入房间码）。
2. 输入昵称 → 点「加入」，等房主开始。

**单机练习**：首页选好 AI 阵容（默认 4 个，点性格标签可切换）→「开始单机」，不需要联网。

> 房主的浏览器负责洗牌发牌：房主请保持页面在前台、屏幕常亮（最好用电脑或平板当房主）。

## AI 性格（v3）
每个 AI 都有固定、一致、几手牌就能感觉出来的打法（还会带一点随机性和下注尺度变化，输了大锅会“上头”几手）：

| AI | 性格 | 打法 | 实测（3000 手，4 人桌） |
|---|---|---|---|
| 🌸 粉哥 | 🔥 疯狂型 Maniac | 什么牌都想玩，爱加注/反加，连续开火，动不动超池或全下 | VPIP 62% · PFR 44% · 3bet 16% · AF 3.8 · 诈唬占下注 44% |
| 🎩 Micheal | 🪨 紧凶型 Rock | 只玩好牌，一出手就是重注；几乎不诈唬，被大注施压没好牌就弃 | VPIP 14% · PFR 9% · 面对大注弃牌 71% · 诈唬 11% |
| 🤖 Grok Bot | 🦊 诡诈型 Trickster | 大牌慢打埋伏、爱过牌加注、下注尺度忽大忽小、河牌偶尔诈唬加注 | 慢打 49% · 过牌加注 12% · 下注尺度 26%–154% 池 |
| 🐲 小龙 | 🐟 跟注站 Calling Station | 什么都跟，很少加注；听牌一定追，很难被诈唬走 | VPIP 61% · PFR 4% · 跟注占决策 47% · 面对 c-bet 只弃 7% |
| 🦊 阿杰等 | 🎯 稳健型 Regular | 标准打法（v2 的“平衡型”） | VPIP 31% · PFR 20% |

`node tools/botstats.mjs 3000` 打印每个 AI 的 VPIP / PFR / 3bet / AF / c-bet / fold-to-c-bet / 过牌加注 / 慢打 / WTSD / 诈唬率 / 下注尺度 / 上头比例；
`LINEUP="粉哥:maniac,Micheal:rock" node tools/botstats.mjs` 自定义阵容；`node tools/vs-human.mjs` 测 AI 面对激进玩家的表现。

## 功能
- 高级感界面：灯光绒布桌面 + 暗角、皮革桌沿金线、标准扑克牌（宫廷牌徽记、蓝金牌背）、带面值的筹码堆、头像 + 性格标签 + 庄家/SB/BB 标记。手机竖屏与电脑都适配（顶部座位的牌不会再盖住顶栏）。
- 反馈：发牌/翻牌动画、下注筹码从座位飞到桌面、收池、底池飞向赢家；轮到谁谁的头像有倒计时光环（AI 思考时转圈 +「思考中…」）；每个动作弹出气泡（加注 / 跟注 / 弃牌 / 全下）；
  实时显示你的牌力（如「两对」「同花听牌」）+ 胜率条；加注面板（½ 池 / ¾ 池 / 1 倍池 / 全下 + 滑块 + ± 微调）；摊牌时赢的五张牌高亮抬起 + 结果横幅；
  WebAudio 合成音效（右上角 🔊 可静音）；手机轮到你时震动；电脑可用快捷键 F 弃牌 / C 过牌跟注 / R 加注；支持系统「减少动态效果」。
- 2–8 人，无限注规则：盲注、翻牌前/翻牌/转牌/河牌，弃牌/过牌/跟注/下注/加注/全下，最小加注规则（不足额全下不重新开放加注）。
- 边池、平分底池（零头筹码给庄家左手边最近的赢家）、完整牌型比较（含踢脚）、摊牌亮牌、庄家按钮轮转。
- 筹码输光即出局，房主可补码到 100,000（AI 输光会自动补码）。
- 洗牌使用 `crypto.getRandomValues`（无偏 Fisher–Yates），只在房主浏览器进行；每位玩家只会收到自己的底牌。
- 每回合计时（默认 30 秒），超时自动过牌/弃牌；连续两次超时自动暂离。
- 断线：轮到断线玩家时自动过牌/弃牌，之后的牌局自动暂离；同一浏览器标签页刷新可重连回原座位。

## 技术
- 纯静态站点（GitHub Pages）。ES modules，无构建步骤。
- 联机（v4）：两条通道，房主权威，客户端只发送操作。
  - **直连**：[PeerJS](https://peerjs.com/)（内置 `vendor/peerjs.min.js`）+ Google/Cloudflare STUN，WebRTC 浏览器直连。
  - **加密中继**（`js/relay.js`）：直连 2.5 秒内没连上就自动改走免费公共 MQTT-over-WSS 服务器（shiftr.io 公共实例走 443 端口，另有 HiveMQ / EMQX / Mosquitto 备用；房主同时监听全部，朋友连上哪个用哪个）。所有消息用 AES-GCM 端到端加密，密钥只在邀请链接 `#k=…` 里（# 后面的部分不会发给任何服务器），服务器只能看到乱码；带序号防重放。适用于 4G/5G 运营商级 NAT、对称 NAT、只放行 443 的网络。
  - 断线自动重连（切后台回来、网络切换会立即重连），右上角显示「直连 / 中继 / 重连中 / 已断开（点击重试）」。
  - 调试：`?net=relay` 强制中继，`?net=direct` 只用直连。
- `js/engine.js` 规则引擎 · `js/evaluator.js` 牌力评估 · `js/pots.js` 边池 · `js/bot.js` AI 性格 · `js/controller.js` 房主调度 · `js/net.js` 联机 · `js/app.js` 界面 · `js/handinfo.js` 牌力提示/最佳五张 · `js/sound.js` 合成音效。

## 已知限制
- 依赖免费公共服务器（PeerJS 信令、公共 MQTT 服务器），没有 SLA；四个中继服务器同时宕机时才会连不上。
- 只输入房间码（不用链接）时没有密钥，只能走直连；用完整邀请链接最稳。
- 中继延迟约 0.2–0.5 秒，打牌无感。
- 房主关闭页面或手机锁屏/切到后台过久，牌局会中断（手机浏览器会暂停后台页面）。
- 牌局状态只保存在房主浏览器内存中，刷新房主页面会丢失牌局。
- 音效需要先点一下页面才能播放（浏览器限制）；iPhone 不支持网页震动。
- AI 用蒙特卡洛估算胜率，性格是“风格”而不是最优策略：疯狂型和跟注站长期会输筹码，这是设计如此。
