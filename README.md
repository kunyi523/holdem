# ♠ 德州扑克 · 朋友局 (No-Limit Texas Hold'em, play money)

在线玩：**https://kunyi523.github.io/holdem/**

免费、纯网页、无需注册的无限注德州扑克，给朋友们娱乐用。
**仅使用虚拟筹码**：每人 100,000 娱乐筹码，没有充值、没有真钱、没有任何支付功能。

## 怎么玩（中文）

**开房间（房主）**
1. 打开网址，输入昵称，点「创建房间」。
2. 弹出房间码和邀请链接，点「复制邀请链接」发到微信群。
3. 朋友到齐后点牌桌中间的「▶ 开始游戏」。人不够可以点空位「＋添加AI」（粉哥 / Micheal / Grok Bot …）。
4. 左上角 ☰ 菜单：调盲注（默认 500/1,000）、行动时间、补码到 100,000、移除玩家、暂停。

**加入（朋友）**
1. 点房主发的链接（或在首页输入房间码）。
2. 输入昵称 → 点「加入」，等房主开始。

**单机练习**：首页选择 AI 数量 → 「开始单机」，不需要联网。

> 房主的浏览器负责洗牌发牌：房主请保持页面在前台、屏幕常亮（最好用电脑或平板当房主）。

## 功能
- 高级感界面：皮革木纹桌沿 + 绒布质感桌面、标准扑克牌（大角标、红黑花色、牌背花纹）、发牌/翻牌动画、分面值筹码堆与筹码飞入底池、头像 + 倒计时光环、庄家按钮、赢家高亮 + 牌型横幅。手机竖屏与电脑都适配。
- 2–8 人，无限注规则：盲注、翻牌前/翻牌/转牌/河牌，弃牌/过牌/跟注/下注/加注/全下，最小加注规则（不足额全下不重新开放加注）。
- 边池、平分底池（零头筹码给庄家左手边最近的赢家）、完整牌型比较（含踢脚）、摊牌亮牌、庄家按钮轮转。
- 筹码输光即出局，房主可补码到 100,000。
- 洗牌使用 `crypto.getRandomValues`（无偏 Fisher–Yates），只在房主浏览器进行；每位玩家只会收到自己的底牌。
- 每回合计时（默认 30 秒），超时自动过牌/弃牌；连续两次超时自动暂离。
- 断线：轮到断线玩家时自动过牌/弃牌，之后的牌局自动暂离；同一浏览器标签页刷新可重连回原座位。
- AI（v2）：
  - 翻牌前：169 种起手牌强度排名 + 每个性格的入池/加注范围 + 位置 + 对手加注尺度（粉哥 VPIP≈42%、Micheal≈21%、Grok Bot≈28%）。
  - 翻牌后：按对手翻牌前行为估计其范围，蒙特卡洛算胜率，再和底池赔率比较；听牌（同花/顺子听牌）会跟注或半诈唬，翻牌前加注者会持续下注（c-bet），偶尔诈唬、偶尔“漂浮”跟注。
  - 记住每个玩家的风格：对一直加注的玩家会放宽跟注/反加范围。可以过牌时绝不弃牌。
  - `node tools/botstats.mjs 1000` 输出 AI 统计（VPIP/PFR/弃牌率/c-bet/WTSD）；`node tools/vs-human.mjs` 测 AI 面对激进玩家的表现。

## 技术
- 纯静态站点（GitHub Pages）。ES modules，无构建步骤。
- 联机：[PeerJS](https://peerjs.com/)（已内置 `vendor/peerjs.min.js`），使用 PeerJS 免费公共信令服务器 + Google/Cloudflare STUN，数据通过 WebRTC 在浏览器之间直连。房主权威，客户端只发送操作。
- `js/engine.js` 规则引擎 · `js/evaluator.js` 牌力评估 · `js/pots.js` 边池 · `js/bot.js` AI · `js/controller.js` 房主调度 · `js/net.js` 联机 · `js/app.js` 界面。

## 已知限制
- 依赖 PeerJS 免费公共信令服务器（0.peerjs.com），偶尔可能不稳定；连不上时稍后重试即可。
- 没有 TURN 中继服务器：极少数网络（对称 NAT、部分公司/校园网、某些移动网络）之间 WebRTC 可能无法直连。换 Wi-Fi/4G 一般可解决。
- 房主关闭页面或手机锁屏/切到后台过久，牌局会中断（手机浏览器会暂停后台页面）。
- 牌局状态只保存在房主浏览器内存中，刷新房主页面会丢失牌局。
